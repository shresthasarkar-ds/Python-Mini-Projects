# Python-Mini-Projects
A collection of beginner-friendly Python command-line projects, including an EMI calculator, mini banking system, temperature converter, password strength checker, budget calculator, and student grade calculator. Built to practice Python fundamentals such as functions, loops, conditions, input validation, and problem-solving.



## Projects

### 1. Budget Calculator🧮

File: `budget_calculate.py`

Calculates total expenses, remaining balance, and estimated savings over a selected number of days. It uses income, rent, travel, and food expenses to provide a simple budget summary.

### 2. Loan EMI Calculator💵

File: `emi_calculation.py`

Calculates the monthly EMI, total interest payable, and total repayment amount based on the loan amount, tenure, and annual interest rate.

### 3. Mini Banking System🏦

File: `mini_banking.py`

A menu-based banking application that allows users to deposit money, withdraw money, check their balance, and exit safely.

### 4. Password Strength Checker🔑

File: `password_strength_checker.py`

Checks whether a password is weak, medium, or strong by evaluating its length and the use of uppercase letters, lowercase letters, numbers, and special characters.

### 5. Student Grade Calculator👩‍🎓

File: `student_grade_calculator.py`

Accepts marks for three subjects, calculates the total and average, and assigns a grade based on the final result.

### 6. Temperature Converter🌡️

File: `temperature_converter.py`

Converts temperatures between Celsius and Fahrenheit with user input validation.

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/shresthasarkar-ds/Python-Mini-Projects.git
```

2. Open the project folder.

3. Run any program using Python. For example:

```bash
python scripts/emi_calculation.py
```
